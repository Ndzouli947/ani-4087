# Exercice 1 — Les trois cadences

## Calculs

La durée d'une image est donnée par :

T = 1000 / fréquence

Le système utilise 8 ms pour les capteurs, la transmission, la composition et l'affichage.

- 72 Hz : 1000 / 72 = 13,9 ms → 13,9 - 8 = **5,9 ms**
- 90 Hz : 1000 / 90 = 11,1 ms → 11,1 - 8 = **3,1 ms**
- 120 Hz : 1000 / 120 = 8,3 ms → 8,3 - 8 = **0,3 ms**

## Résultats

- 72 Hz : **5,9 ms**
- 90 Hz : **3,1 ms**
- 120 Hz : **0,3 ms**
